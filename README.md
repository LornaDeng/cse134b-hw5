# CSE 134B Homework 5

This repository contains Wenqing Deng's HW5 portfolio, the Cat Fact Web Component on `projects.html`, and an Eleventy static-site-generator exercise in `ssg-exercise/`.

The component shows three local sample facts and can request a live fact from the Cat Fact API. It supports compact and expanded modes, follows the portfolio's light and dark themes, and remembers the visitor's mode with `localStorage`.

The SSG exercise generates Home and About pages from Nunjucks templates and a shared footer. See `ssg-exercise/README.md` for setup, build, and preview commands.

The full submission URLs are listed in `links.txt`.
